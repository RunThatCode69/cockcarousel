# Cock Carousel — App Store release runbook

Everything below `ios-app/` is set up so that after a one-time setup, shipping is one command.
Honest timeline: **submit tonight → Apple review 24–48 h → live.** Nobody can make it live tonight.

## 0. Reality check on review (read once)
Apple guideline 1.1.4 bars "overtly sexual" content. The character itself is cartoon crude humor and has a real shot at 17+.
The three things most likely to get a rejection are: the ejaculation game-over, the humping/booty win screen, and the /sperm game.
This wrapper ships the slide game only. If review bounces it, the fix is a "store cut" (tamer game-over + win screen) — ask Claude, it's a small change, then `npm run release` again.

## 1. One-time, by you (≈ 30 min if you already have an Apple Developer account; +1–2 days if you're enrolling)
1. Apple Developer Program: developer.apple.com/programs ($99/yr). Enrollment must be *approved* before anything else works.
2. Xcode from the Mac App Store (big download — start it first). Then: `xcode-select --install`, open Xcode once, accept the license.
3. App Store Connect → **Users and Access → Integrations → App Store Connect API → Generate API Key**, role **Admin**.
   Download the `.p8` (only downloadable once) → save as `ios-app/fastlane/AuthKey.p8`. Note the Key ID and Issuer ID.
4. `cp .env.example .env` and fill in `APPLE_TEAM_ID` (developer.apple.com → Membership), `ASC_KEY_ID`, `ASC_ISSUER_ID`.
5. App Store Connect → **My Apps → + → New App**: iOS, name `Cock Carousel`, primary language English (U.S.), bundle ID `com.cockcarousel.sliderush` (create it there if not listed), SKU `cockcarousel`. Claude can click through this in your Chrome if you're logged in.
6. In that app record, two things fastlane can't set: **Age Rating** (Sexual Content/Nudity: Frequent/Intense → 17+; Mature/Suggestive Themes: Frequent/Intense) and **App Privacy → Data Not Collected**.
7. Deploy the website changes (privacy + support pages) so `cockcarousel.com/privacy` and `/support` resolve — they're in the review form.
8. Put a real phone number in `fastlane/metadata/review_information/phone_number.txt` (placeholder now).

## 2. Build + submit (autonomous from here)
```bash
cd ~/Desktop/cockcarousel/ios-app
bash setup.sh          # once: installs deps, creates the Xcode project, icons, splash, plist tweaks
npm run beta           # optional: TestFlight build to play on your phone first (recommended, 10 min)
npm run release        # builds, signs, uploads binary + metadata + screenshots, SUBMITS FOR REVIEW, auto-releases on approval
```
Every `npm run release` bumps the build number. Version stays 1.0.0 unless you change it in Xcode / `agvtool new-marketing-version 1.1.0`.

## 3. Updating the game later
Edit `../game/index.html` (the web version), then:
```bash
npm run pull-game      # copies it in, re-inlines the offline font, syncs
npm run release
```

## What's in here
- `www/index.html` — the game, font bundled (works offline), iOS viewport tweaks
- `assets/` — 1024 icon, 2732 splash (all sizes generated by `npm run assets`)
- `fastlane/Fastfile` — `beta` (TestFlight) and `release` (App Store + submit) lanes, API-key signing, no Xcode clicking
- `fastlane/metadata/` — name, subtitle, description, keywords, URLs, category, review notes
- `fastlane/screenshots/en-US/` — six 6.7" (2796×1290) captioned screenshots, iPhone only (TARGETED_DEVICE_FAMILY=1 so no iPad set needed)
- `setup.sh` / `release.sh` — the two commands
